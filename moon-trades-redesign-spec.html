The Platform
Three layers of intelligence. One platform.

 

Layer 1: Satellite & Aerial Data

High-resolution satellite imagery and aerial surveys form the foundation. PEBBLE™ processes multispectral and hyperspectral data to identify geological signatures invisible to the human eye — mapping mineralogy, structure, and alteration zones from orbit.

Layer 2: Ground Truth & Historical Data

Historical drill logs, geochemical surveys, geological maps, and field observations are integrated and cross-referenced with satellite data. PEBBLE™ normalizes decades of scattered datasets into a single, queryable terrain model.

Layer 3: Autonomous Sensing

PEBBLE™'s autonomous vehicles carry XRF (X-ray fluorescence) and LIBS (laser-induced breakdown spectroscopy) sensors for real-time, in-the-field geochemical analysis. They operate in terrain too remote, dangerous, or extreme for human teams — around the clock, in any weather.

IMPLEMENTATION

Technical Notes

Analytics Setup

Implementation

Google Analytics 4 (GA4): Set up a GA4 property and add the measurement ID in Framer's project settings (Settings → General → Custom Code → Head). Track page views, scroll depth, CTA clicks, and form submissions as custom events.

Key events to track:

  • cta_click — with parameters: button_text, page, destination
  • form_submit — with parameters: form_type (contact, newsletter), audience_type
  • calendly_click — tracks demo booking intent
  • media_kit_download — tracks press engagement
  • scroll_depth — 25%, 50%, 75%, 100% per page

Google Search Console: Verify ownership to monitor organic search performance and indexing.

Pixel Tracking

Implementation

LinkedIn Insight Tag: Essential for B2B — tracks company demographics of visitors. Install via Framer custom code (head section). Set up conversion events for form submissions and demo bookings.

Meta Pixel (optional): If Moon Trades runs Facebook/Instagram ads, install the pixel for retargeting. Track PageView, Lead (form submit), and Schedule (Calendly click) events.

Note: Add all pixels through Framer's custom code injection (Settings → Custom Code) to keep them outside the page components. Use a cookie consent banner for GDPR/PIPEDA compliance — Framer has built-in cookie consent or use CookieYes.

Email Capture

Implementation

Recommended: Mailchimp or ConvertKit. Both integrate with Framer's native form component. Create an audience/list with tags for source page and audience type.

Form handling options in Framer:

  • Framer native forms — simplest, sends to email or webhook
  • Mailchimp embedded form — direct list integration
  • ConvertKit form — better for sequences and tagging
  • Zapier webhook — most flexible, connects to any CRM

Segmentation: Tag subscribers by source: "newsletter" (email capture bar), "contact-form" (contact page), and audience type from the dropdown.

Calendly Integration

Implementation

Current link: calendly.com/wintta-moontrades/30min. In Framer, use a simple button link to Calendly (opens in new tab) rather than an embed — Calendly iframes can be slow and don't always render well on mobile. Style the button prominently. Consider adding UTM parameters to the Calendly link to track which page the booking came from.

QA

Mobile & Performance

Mobile-First Checklist

  • Navigation: Hamburger menu, slide-in drawer, full-height dark background
  • Touch targets: All buttons and links minimum 44×44px tap area
  • Font sizes: Body minimum 16px (prevents iOS zoom on input focus), headlines minimum 28px
  • Images: Serve responsive images via Framer's built-in optimization. Use WebP format.
  • Forms: Full-width inputs on mobile, proper input types (email, tel), visible labels above fields
  • CTAs: Full-width buttons on mobile, sticky CTA bar at bottom of homepage (optional)
  • Horizontal scroll: None. Test at 375px, 390px, 414px widths
  • Section padding: 48px top/bottom on mobile (vs 80px+ desktop)
  • Card grids: Always single column on mobile, stack order matches reading order

Performance Targets

  • Lighthouse Performance: Target 90+ on mobile
  • LCP (Largest Contentful Paint): Under 2.5s — optimize hero images, use Framer's lazy loading
  • CLS (Cumulative Layout Shift): Under 0.1 — set explicit dimensions on images, avoid layout-shifting fonts
  • FID (First Input Delay): Under 100ms — minimize third-party scripts
  • Image optimization: Framer handles this natively. Ensure hero images are under 200KB compressed.
  • Font loading: Use font-display: swap to prevent FOIT (flash of invisible text)
  • Third-party scripts: Load analytics and pixels asynchronously. Defer non-critical scripts.

Testing Devices

Test on these breakpoints and devices before launch:

  • Mobile: iPhone 14/15 (390px), iPhone SE (375px), Samsung Galaxy S23 (360px)
  • Tablet: iPad (768px), iPad Pro (1024px)
  • Desktop: 1280px, 1440px, 1920px
  • Browsers: Chrome, Safari (especially mobile Safari), Firefox, Edge

SEO Essentials

  • Page titles: "Moon Trades | AI for Critical Mineral Exploration" (home), unique per page
  • Meta descriptions: Unique, 150–160 chars, include "PEBBLE" and "mineral exploration"
  • OG tags: Set per page with appropriate images for social sharing
  • Heading hierarchy: Single H1 per page, logical H2→H3 nesting
  • Alt text: Descriptive alt text on all images
  • Sitemap: Framer generates automatically
  • Favicon: Use existing Moon Trades icon, ensure it's set in Framer project settings
